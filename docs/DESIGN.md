# Dirección visual

NEXUS utiliza una paleta de tinta y violeta sobre un fondo frío. La portada tiene una órbita animada dibujada en SVG. La tipografía del sistema, la escala de espacios y los iconos comparten ritmo entre las vistas. Los temas claro y oscuro incluyen la navegación, el editor y el lienzo del grafo.

En iPhone, la barra de pestañas flota sobre el contenido. El material web combina desenfoque y saturación del fondo, bordes luminosos y una lente que se desplaza hasta la pestaña activa. El buscador y el editor se presentan como hojas inferiores. El editor conserva el botón Guardar arriba al recorrer el documento.

Las transiciones de navegación y del indicador usan transformaciones y opacidad. El sistema respeta movimiento reducido, transparencia reducida cuando el navegador la expone y el ajuste manual. Se conservan objetivos táctiles de 44 px, áreas seguras y la navegación por teclado. La visualización del grafo tiene una lista de nodos alternativa.

- [Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)
- [Apple HIG Tab Bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)
- [Apple HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion)
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)
